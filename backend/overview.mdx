## Introduction

The backend is built with **FastAPI**, a modern Python web framework known for its high performance, automatic API documentation, and type safety through Pydantic.

## Key Components

### 1. Application Entry (`main.py`)

Initializes the FastAPI app with lifespan management for database connections.

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup: Connect to MongoDB
    await connect_to_mongo()
    yield
    # Shutdown: Close connections
    await close_mongo_connection()

app = FastAPI(
    title="Akdeniz CSE AI Assistant",
    lifespan=lifespan
)
```

**Key Features:**
- ✅ Automatic OpenAPI/Swagger docs at `/docs`
- ✅ Async lifecycle management
- ✅ Health check endpoint at `/health`
- ✅ CORS middleware for WhatsApp bot integration

### 2. Configuration (`app/core/config.py`)

Type-safe configuration using Pydantic Settings.

```python
class Settings(BaseSettings):
    PROJECT_NAME: str = "FastAPI Project"
    MONGO_CONNECTION_STRING: str
    MONGO_DB_NAME: str
    GEMINI_API_KEY: str
    
    # Ollama Configuration
    OLLAMA_BASE_URL: str = "http://localhost:11434"
    OLLAMA_MODEL: str = "qwen2:7b"
    OLLAMA_TEMPERATURE: float = 0.3
    
    # Strategy Selection
    CLASSIFICATION_METHOD: Literal["ollama", "fuzzy", "hybrid"] = "hybrid"

    model_config = SettingsConfigDict(
        env_file=".env",
        env_ignore_empty=True
    )
```

<Tip>
All configuration is loaded from environment variables, making it easy to deploy to different environments.
</Tip>

### 3. Database Layer (`app/db/mongo.py`)

Singleton pattern for MongoDB connection management.

```python
class MongoDB:
    client: AsyncIOMotorClient = None
    db = None

db = MongoDB()

async def connect_to_mongo():
    db.client = AsyncIOMotorClient(settings.MONGO_CONNECTION_STRING)
    db.db = db.client[settings.MONGO_DB_NAME]
    await db.client.admin.command('ping')
```

**Benefits:**
- Single database connection instance
- Automatic connection pooling
- Async/await support with Motor
- Graceful connection/disconnection

## API Routes

### Chat Endpoint (`/api/chat/`)

Main conversation endpoint that orchestrates the entire flow.

```python
@router.post("/", response_model=ChatResponse)
async def chat_endpoint(request: ChatRequest) -> ChatResponse:
    # 1. Classify intent
    intent = await decide_intent(request.message)
    
    # 2. Fetch context based on intent
    if intent == "dining":
        context_data = await _fetch_dining_context()
    elif intent == "announcement":
        context_data = await _fetch_announcements_context()
    else:
        context_data = "General conversation."
    
    # 3. Generate response with Gemini
    reply = await generate_response(
        system_instruction=SYSTEM_INSTRUCTION,
        user_query=request.message,
        context_data=context_data
    )
    
    return ChatResponse(reply=reply, source=intent)
```

**Request Schema:**
```json
{
  "message": "Bugün yemekte ne var?",
  "user_id": "optional_user_id"
}
```

**Response Schema:**
```json
{
  "reply": "🍽️ Bugünün menüsü:\n\n• Çorba: Mercimek\n...",
  "source": "dining"
}
```

### Dining Endpoint (`/api/dining/{date}`)

Get specific menu by date.

```python
@router.get("/{date_str}", response_model=DiningMenuResponse)
async def get_dining_menu_by_date(date_str: str):
    menu = await db.db["yemekhane_listesi"].find_one({"date": date_str})
    
    if not menu:
        raise HTTPException(status_code=404, detail="No menu found")
    
    return DiningMenuResponse(**menu)
```

### Announcements Endpoint (`/api/announcements/`)

Get latest announcements.

```python
@router.get("/", response_model=List[AnnouncementResponse])
async def get_latest_announcements():
    cursor = (
        db.db["cse_akdeniz_announcements"]
        .find()
        .sort("created_at", -1)
        .limit(10)
    )
    announcements = await cursor.to_list(length=10)
    return announcements
```

## Request/Response Flow

<Steps>
  <Step title="Client Request">
    Mobile app or WhatsApp bot sends POST to `/api/chat/`
  </Step>
  <Step title="Input Validation">
    Pydantic validates request against `ChatRequest` schema
  </Step>
  <Step title="Intent Classification">
    Factory pattern instantiates appropriate classifier (Ollama/Fuzzy/Hybrid)
  </Step>
  <Step title="Context Retrieval">
    Query MongoDB for relevant data based on classified intent
  </Step>
  <Step title="Response Generation">
    Gemini generates natural language response with context
  </Step>
  <Step title="Response Delivery">
    FastAPI serializes response to JSON and returns to client
  </Step>
</Steps>

## Error Handling

All endpoints include comprehensive error handling:

```python
try:
    # Main logic
    pass
except HTTPException as http_err:
    raise http_err  # Pass through HTTP exceptions
except Exception as e:
    logger.error(f"Unexpected error: {e}")
    raise HTTPException(
        status_code=500,
        detail=f"Internal server error: {str(e)}"
    )
```
