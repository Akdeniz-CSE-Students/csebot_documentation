## Key Components

### 1. Intent Classifier (Strategy + Factory)

**Location**: `backend/app/llm_engine/classifier.py`

The classifier uses both **Strategy** and **Factory** patterns:

```python
# Factory with OCP-compliant dictionary map
CLASSIFIER_MAP = {
    "ollama": _create_ollama_classifier,
    "fuzzy": _create_fuzzy_classifier,
    "hybrid": _create_hybrid_classifier,
}

def get_classifier() -> IntentClassifier:
    method = settings.CLASSIFICATION_METHOD  # From .env
    factory_fn = CLASSIFIER_MAP.get(method, _create_fuzzy_classifier)
    return factory_fn()
```

**Configuration** (`.env`):
```env
CLASSIFICATION_METHOD=hybrid  # Options: ollama, fuzzy, hybrid
FUZZY_THRESHOLD=80
```

### 3. MongoDB Singleton

**Location**: `backend/app/db/mongo.py`

Thread-safe singleton with encapsulated state:

```python
class MongoDB:
    def __init__(self):
        self._client = None
        self._db = None
        self._initialized = False
    
    @property
    def client(self):
        if self._client is None:
            raise RuntimeError("Not connected")
        return self._client

db = MongoDB()  # Global singleton
```

### 5. WhatsApp Integration

**Location**: `whatsapp/`

Node.js service using WPPConnect. Acts as a "dumb terminal":

```javascript
// Receives message → Forwards to Python → Sends reply
client.onMessage(async (message) => {
    const response = await axios.post(BACKEND_URL + '/api/chat', {
        message: message.body,
        group_id: message.from
    });
    await client.sendText(message.from, response.data.reply);
});
```

> [!TIP]
> This separation allows updating AI logic without restarting WhatsApp (which requires QR scanning).

## Configuration

### Environment Variables

```env
# Database
MONGO_CONNECTION_STRING=mongodb://localhost:27017
MONGO_DB_NAME=chatbot

# AI Services
GEMINI_API_KEY=your_api_key
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2:7b

# Classification
CLASSIFICATION_METHOD=hybrid
FUZZY_THRESHOLD=80
```

### Pydantic Settings

```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    MONGO_CONNECTION_STRING: str
    GEMINI_API_KEY: str
    CLASSIFICATION_METHOD: Literal["ollama", "fuzzy", "hybrid"] = "hybrid"
    
    model_config = SettingsConfigDict(env_file=".env")

settings = Settings()
```
