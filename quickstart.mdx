## Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/ChatbotForCse.git
cd ChatbotForCse
```

## Step 2: Set Up Environment Variables

Create a `.env` file in the project root:

```bash .env
# MongoDB Configuration
MONGO_CONNECTION_STRING=mongodb+srv://username:password@cluster.mongodb.net/?retryWrites=true&w=majority
MONGO_DB_NAME=ChatBotCse

# Gemini API Key (get from https://aistudio.google.com/)
GEMINI_API_KEY=your_gemini_api_key_here

# Ollama Configuration
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2:7b
OLLAMA_TIMEOUT=10
OLLAMA_TEMPERATURE=0.3

# Classification Method: "ollama", "fuzzy", or "hybrid"
CLASSIFICATION_METHOD=hybrid

# WhatsApp Bot (Optional)
SESSION_NAME=cse-bot-session
TARGET_GROUP_NAME=CSE BOT
PHONE_NUMBER=905551234567
```

<Warning>
**Never commit your `.env` file to Git!** Make sure `.env` is in your `.gitignore` file.
</Warning>

## Step 3: Install Ollama Model

Pull the Qwen2 model for intent classification:

```bash
ollama pull qwen2:7b
```

<Tip>
Ollama must be running for the backend to work. Start it with `ollama serve` if it's not auto-started.
</Tip>

## Step 4: Set Up MongoDB

<Tabs>
  <Tab title="MongoDB Atlas (Recommended)">
    1. Create a free account at [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)
    2. Create a new cluster
    3. Add your IP to the whitelist (or allow 0.0.0.0/0 for development)
    4. Create a database user
    5. Copy the connection string to your `.env` file
  </Tab>
  
  <Tab title="Local MongoDB">
    ```bash
    # Using Docker
    docker-compose up -d mongo
    
    # Or install locally and use:
    # MONGO_CONNECTION_STRING=mongodb://localhost:27017
    ```
  </Tab>
</Tabs>

## Step 5: Start the Backend

```bash
cd ChatbotForCse

# Install Python dependencies
pip install -r requirements.txt

# Start the FastAPI server
python backend/main.py
```

You should see:
```
INFO:     Started server process
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

<Check>
**Backend is running!** Visit [http://localhost:8000/docs](http://localhost:8000/docs) to see the Swagger UI.
</Check>

## Step 6: Start the Data Pipeline (Optional)

The data pipeline scrapes menus and announcements automatically:

```bash
cd data-pipeline

# Install dependencies
pip install -r requirements.txt

# Start the scheduler
python jobs/run_scheduler.py
```

<Info>
The pipeline runs every 30 minutes by default. You can change this in the `.env` file with `SYNC_INTERVAL=1800`.
</Info>

## Step 8: Run the Mobile App (Optional)

<Steps>
  <Step title="Navigate to mobile-app directory">
    ```bash
    cd mobile-app
    ```
  </Step>
  
  <Step title="Install dependencies">
    ```bash
    npm install
    ```
  </Step>
  
  <Step title="Update API URL">
    Edit `src/core/config.ts`:
    ```typescript
    const DEV_API_URL = 'http://YOUR_COMPUTER_IP:8000';
    ```
    
    <Warning>
    Don't use `localhost` - use your computer's local IP (e.g., `192.168.1.100`)
    </Warning>
  </Step>
  
  <Step title="Start Expo">
    ```bash
    npx expo start
    ```
    
    Scan the QR code with:
    - **iOS**: Camera app
    - **Android**: Expo Go app
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Backend won't start" icon="triangle-exclamation">
    **Issue:** `ModuleNotFoundError` or import errors
    
    **Solution:**
    ```bash
    # Reinstall dependencies
    pip install --upgrade -r requirements.txt
    
    # Make sure you're using Python 3.10+
    python --version
    ```
  </Accordion>
  
  <Accordion title="Ollama connection failed" icon="robot">
    **Issue:** `Connection refused` to Ollama
    
    **Solution:**
    ```bash
    # Check if Ollama is running
    ollama serve
    
    # In another terminal, test:
    ollama run qwen2:7b "Test message"
    ```
  </Accordion>
  
  <Accordion title="MongoDB connection error" icon="database">
    **Issue:** `ServerSelectionTimeoutError`
    
    **Solution:**
    - Check your connection string in `.env`
    - Verify IP whitelist in MongoDB Atlas
    - Test connection: `mongosh "your_connection_string"`
  </Accordion>
  
  <Accordion title="Mobile app can't connect" icon="mobile">
    **Issue:** Network error or timeout
    
    **Solution:**
    - Use your computer's local IP, not `localhost`
    - Ensure phone and computer are on same network
    - Check firewall settings (allow port 8000)
    - Restart the Expo dev server
  </Accordion>
</AccordionGroup>
