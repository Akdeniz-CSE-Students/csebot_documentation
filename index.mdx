## Problem Statement
Students often struggle to access scattered information regarding:
*   Daily dining hall menus.
*   Department announcements (internships, exams, cancellations).
*   Quick answers to academic procedures or general queries.

Existing solutions require checking multiple websites (SKS, CSE Dept) or asking in WhatsApp groups repeatedly.

## Solution: ChatbotForCse
A unified **AI-powered chatbot** accessible via WhatsApp and Mobile App. It aggregates data from various sources and uses LLMs to provide intelligent, context-aware responses.

### Key Features
*   **Dining Menus**: Automatically scrapes and parses weekly menus from the SKS website.
*   **Announcements**: Tracks and delivers the latest department news in real-time.
*   **Intelligent Q&A**: Uses **Gemini** and **Ollama** to answer general questions (math, coding, regulations).
*   **Multi-Channel**: Currently live on WhatsApp, with an API ready for mobile integration.
