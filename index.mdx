## Welcome to CSE Chatbot 🤖

The **Akdeniz CSE AI Assistant** is a comprehensive multi-platform chatbot system designed to help Computer Engineering students at Akdeniz University access information quickly and efficiently.

## Architecture Overview

The system follows a **microservices architecture** with four main components:

<Steps>
  <Step title="Backend API (FastAPI)">
    Central brain handling requests, database operations, and AI orchestration
  </Step>
  <Step title="LLM Engine">
    Intent classification and response generation using Gemini & Ollama
  </Step>
  <Step title="Data Pipeline">
    Automated scraping, cleaning, and indexing of university data
  </Step>
  <Step title="WhatsApp Client">
    WhatsApp bot powered by WPPConnect for student access
  </Step>
</Steps>

## Tech Stack

<Columns cols={2}>
  <div>
    ### Backend
    - **FastAPI** - High-performance async API framework
    - **Motor** - Async MongoDB driver
    - **Gemini 2.5 Flash** - Advanced LLM for responses
    - **Ollama (Qwen2:7b)** - Local intent classification
  </div>
  <div>
    ### Client & Data
    - **WPPConnect** - WhatsApp Web integration
    - **MongoDB** - NoSQL database for flexibility
    - **BeautifulSoup** - Web scraping engine
    - **Gemini Vision** - OCR for menu images
  </div>
</Columns>
