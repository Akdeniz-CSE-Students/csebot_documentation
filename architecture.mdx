## System Overview

ChatbotForCse consists of **three independent subsystems** communicating via REST APIs and a shared MongoDB database.

```mermaid

    API <-->|Response Generation| Gemini
    API <-->|CRUD| DB
    
    Pipeline -->|Scrape| SKS
```

## Layered Architecture

The backend follows a clean **4-layer architecture**:

```mermaid
graph TB
    subgraph "API Layer"
        A1["/api/chat"]
        A2["/api/dining"]
    end
    
    subgraph "Service Layer"
        S1[chat_service.py]
        S2[dining_service.py]
    end
    
    subgraph "Domain Layer"
        D1[IntentClassifier<br/>Strategy Pattern]
        D2[ContextStrategy<br/>Strategy Pattern]
        D3[LLM Engine]
    end
    
    subgraph "Data Access Layer"
        DA1[MongoDB Singleton]
        DA2[OllamaClient Singleton]
    end
    
    A1 --> S1
    A2 --> S2
    S1 --> D1
    S1 --> D2
    S1 --> D3
    D1 --> DA2
    D2 --> DA1
    D3 --> DA1
```

| Layer | Responsibility | Files |
|-------|----------------|-------|
| **API** | HTTP endpoints, request/response | `api/routes/chat.py` |
| **Service** | Business logic orchestration | `services/chat_service.py` |
| **Domain** | Core algorithms, AI logic | `llm_engine/`, `strategies/` |
| **Data Access** | Database, external clients | `db/mongo.py`, `clients/` |

## Chat Request Data Flow

Detailed sequence of a chat request through the system:

```mermaid
sequenceDiagram
    autonumber
    participant U as User
    participant WA as WhatsApp
    participant WAC as WA Client
    participant API as FastAPI
    participant CL as Classifier
    participant ST as Strategy
    participant DB as MongoDB
    participant LLM as Gemini

    U->>WA: "bugün menüde ne var?"
    WA->>WAC: Message Event
    WAC->>API: POST /api/chat
    
    Note over API: Factory Pattern
    API->>CL: get_classifier().classify()
    CL-->>API: intent = "dining"
    
    Note over API: Factory Pattern
    API->>ST: get_context_strategy("dining").fetch()
    
    Note over ST,DB: Singleton Pattern
    ST->>DB: fetch_dining_data_raw()
    DB-->>ST: List[Dict]
    ST-->>API: formatted_context
    
    API->>LLM: generate(context + query)
    LLM-->>API: response
    
    API->>DB: save_message()
    API-->>WAC: ChatResponse
    WAC-->>WA: Reply
    WA-->>U: "Bugün köfte var..."
```
